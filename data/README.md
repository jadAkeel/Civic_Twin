# CityMind Tripoli Data

This directory contains Tripoli-specific demo seed data for the CityMind Tripoli
prototype.

`tripoli_seed.json` is Phase 2 demo data for database development. It includes
approximate neighborhood centroids, reports, assets, scores, mobility edges, and
draft scenarios. It is not official municipal GIS data, and every value must be
validated with local sources, OpenStreetMap, municipality data, field checks, or
citizen reports before being treated as real-world evidence.
